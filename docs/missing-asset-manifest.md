## 3. Required User / Project Owner Action

To transition any or all of these 25 Midjourney drafts into published, live showcase posts:

### Option A: Local File Supply & Automated Importer
1. Generate the image in your licensed Midjourney subscription using the prompt provided in each record.
2. Place the resulting image files into `public/images/midjourney/` named after the key:
   ```bash
   public/images/midjourney/mj-portrait-01.jpg
   public/images/midjourney/mj-portrait-02.jpg
   # ... up to mj-fashion-05.jpg
   ```
3. Run the automated import utility with the `--publish-mj` flag:
   ```bash
   node scripts/import-revised-step10.mjs --publish-mj
   ```
4. The importer validates that the files physically exist on disk, updates `assetStatus` to `READY`, sets `status` to `published`, and upserts to the database.

### Option B: Administrator Console Upload
1. Log into your PromptNest account with administrator rights.
2. Navigate to `/admin/prompts/new` (or click Edit on any draft prompt in `/admin`).
3. Upload your Midjourney export file through the Sharp-validated media pipeline (strips EXIF, enforces dimensions, converts to WebP).
4. Review the substantive prompt, verify the "Recreation prompt" or "Original generation prompt" label, and toggle publication state to **Published**.
